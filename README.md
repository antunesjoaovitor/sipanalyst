# SIPAnalyst

SIPAnalyst é um assistente especializado no protocolo SIP (Session Initiation Protocol), treinado com o conteúdo completo das RFCs relacionadas ao SIP para fornecer respostas rápidas, precisas e contextualizadas.

O projeto foi desenvolvido para auxiliar necessidades e dúvidas relacionadas ao VoIP, telecomunicações, redes e suporte técnico na consulta e interpretação de especificações SIP sem a necessidade de pesquisar manualmente centenas de páginas de documentação.

## Funcionalidades

* Consulta instantânea sobre SIP
* Respostas baseadas nas RFCs oficiais
* Explicações de métodos SIP
* Interpretação de códigos de resposta
* Auxílio em troubleshooting
* Orientação sobre fluxo de sinalização
* Referência rápida para engenheiros e analistas VoIP

## Como funciona

* O usuário envia uma dúvida relacionada ao protocolo SIP.
* A IA consulta sua base de conhecimento construída a partir das RFCs.
* A resposta é gerada de forma contextualizada e objetiva.
* O usuário recebe a informação em segundos.

## Exemplos de perguntas

* O que significa um SIP 488?
* Quando utilizar ACK?
* Como funciona o processo de registro SIP?
* Qual a diferença entre 401 e 407?
* Como interpretar uma INVITE com SDP?

## Tecnologias

* HTML
* CSS
* JavaScript
* PHP
* N8N
* APIs de IA (Groq)
* Base de conhecimento construída a partir das RFCs SIP
* Banco de dados SQL

## Objetivo

Transformar centenas de páginas de documentação técnica em uma ferramenta de consulta instantânea para profissionais que trabalham diariamente com VoIP e SIP.
